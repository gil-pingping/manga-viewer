# 로컬 목업 사이트 (수집 규칙 테스트용)

파일명 모양이 같은 본문 덩어리 위에 로고·단발 파일이 얹힌 구조를 재현한다.
연번(`p001.jpg`)이 아니라 `시각_해시.svg` 형태라 `findDominantShape` 경로를 탄다.

    python3 -m http.server 8901 --directory test/mocksite

뷰어에서 `http://localhost:8901/` 를 붙여넣으면 본문 14장만 잡혀야 한다
(로고 2장 + 단발 타임스탬프 1장은 걸러진다).

주의: 프록시의 사설망 가드는 **요청자가 루프백일 때만** 로컬 주소를 허용한다.
태블릿(LAN)에서 열면 이 목업은 못 불러온다 — 의도된 동작이다.
